🧶 拼豆变围巾

把你做好的拼豆作品，变成一条可以织出来的围巾。

📷 拍照上传→ 🟥 变成电子图纸→ ✏️ 修改图纸→ 📋 生成花卡→ 🧣 看围巾效果

整个过程大约 5 分钟，不需要任何电脑基础。照片只在你自己的电脑里处理，不会上传到网上。

📄 拼豆变围巾.html网站本体。双击打开就能用。
🍓 示例拼豆-草莓.jpg一张示例照片。手边没有拼豆照片时，可以先用它试一试。

本教程的最后一页是「测试反馈清单」，用完后请帮忙填一下 🙏

0打开网站

  1. 把收到的 拼豆变围巾.html 保存到电脑上（比如桌面）。
  2. 双击它，它会在浏览器里打开。推荐用 Chrome、Safari 或 Edge。
    如果双击后打开的不是浏览器：右键文件 →「打开方式」→ 选择 Chrome 或 Safari。
  3. 右上角可以切换 中文 / EN。

打开后看到的首页。顶部是 5 个步骤，做完一步会打上 ✓。

💡 建议用电脑打开，屏幕大一点，编辑图纸更方便。不需要联网，也不用注册登录。

📸 拍照小贴士

  • 从正上方拍，手机尽量和作品平行，不要斜着拍。
  • 光线均匀，避免强烈的反光和阴影（白天靠窗最好）。
  • 整个作品都要在画面里，最好放在颜色单一的背景上（例如白纸或拼豆板）。
  • iPhone 照片如果是 HEIC 格式，网站可能读不了。可以先截个屏，或者在相册里「导出为 JPG」。

1上传照片 · 摆正裁剪

  1. 点击 选择照片，或者直接把照片拖进虚线框里。
  2. 照片上会出现一个橙色的裁剪框。拖动它四个角上的小圆点，让框刚好贴住拼豆的边缘，把桌子、多余的空板都裁掉。
  3. 如果拼豆的行是歪的，拖动左边的 「旋转」滑块把它摆正。⟲ 90° ⟳ 90° 可以整体转向。
  4. 点 下一步 →。

裁剪框贴住了草莓的边缘，外面的部分会变暗，表示被裁掉。

⭐ 裁剪得越准，下一步的效果越好。框里最好正好是「一整颗一整颗的豆子」，不要切到半颗。

2像素化 · 变成电子图纸

网站会把照片切成一个个小格子，每一格对应一颗豆子，并找到最接近的拼豆颜色。

  1. 先点 🔍 自动识别，它会自己数出横竖各有几颗豆子。
    如果数得不对，就在 宽（颗） 和 高（颗） 里手动填你作品真实的豆子数。
  2. 对比右边的电子图纸和左边的照片，看看是否一致。
  3. 满意后点 使用这张图纸 →。

左：原照片　右：生成的电子图纸。下方显示格子大小、颜色数和豆子总数。

其他选项（可以不动）

选项作用
拼豆色卡选择你用的拼豆品牌（MARD / Perler / Hama），或者「从照片取色」。
最多颜色数颜色太多、出现杂色时调小一点。
去除背景勾选后会把作品周围的空板或背景去掉，只留下作品本身。
每颗豆取样范围豆子中间的孔影响了颜色时，可以调小一点。

3编辑图纸

这里可以像画画一样修改图纸，比如修正识别错的颜色。不需要修改的话，直接点 确认图纸 →。

左边：用到的颜色（数字 = 用了几颗）和画布工具　右边：图纸

上方工具栏

✏️画笔：点一下或拖动来放豆子
🧽橡皮：去掉豆子
🪣填充：把一整块相连的同色区域换色
💧吸管：点一颗豆子，取它的颜色
🔁替换颜色：把整张图里这个颜色全部换掉
↶ ↷撤销 / 重做，画错了别担心

怎么换颜色？

  1. 在左边颜色列表里点一下想用的颜色；
  2. 没有这个颜色？点 ＋ 添加颜色 从色卡里选；
  3. 然后用画笔在图纸上点。

其他

  • 缩放滑块可以把图纸放大，方便点小格子。
  • 画布：上/下/左/右 +1 −1 增减一行或一列；也可以翻转、旋转。
  • ⬇ PNG 可以下载这张拼豆图纸。

4花卡 · 针织图解

这一步把拼豆图纸变成毛线编织用的花卡：每个小格 = 一针，每种颜色有自己的符号。

左边调整围巾参数，右边实时显示花卡。

可以调整的地方

设置说明
毛线粗细 / 密度选你打算用的毛线粗细。如果你织过小样，可以填自己量到的「每 10 cm 几针、几行」。
图案宽度图案织多宽（多少针），图案会自动按比例变大或变小。
围巾宽度 / 长度整条围巾的尺寸，右边会显示换算成的厘米数。
图案位置两端各一个（围上后两头都能看到）、居中或重复排列。
边缘桂花针 / 起伏针可以防止围巾边缘卷起来。
主色线围巾底色。
📖 怎么看花卡：第 1 行在最下面，从下往上织。奇数行（正面）从右往左读，偶数行（反面）从左往右读。每 10 格有一条粗线，方便数数。

4花卡 · 颜色图例和下载

往下滚动，可以看到颜色图例：每种颜色的符号、需要织多少针、大约要用多少米毛线。

  • 点颜色方块可以换成你实际买到的毛线颜色；毛线名称可以直接改，比如写上品牌和色号。
  • 顶部的 图案部分 / 整条围巾 可以切换查看范围。
  • 点 ⬇ PDF 下载可打印的花卡（第 1 页是图例），或者 ⬇ PNG 下载图片。
  • 想打印黑白版？取消勾选 「彩色」，只保留符号。
⭐ 用线量是粗略估算，买毛线时建议每种颜色多买一点。

5围巾效果

点 看看围巾效果 →，就能看到织好后的围巾模拟图 🎉

完整视图：两端各有一颗草莓，带流苏和垂坠感。

点「近看」可以看到一针一针的毛线质感。

  • 线圈大小 / 毛线粗细 / 毛绒感：调整质感；流苏、垂坠褶皱、阴影可以开关。
  • 横向 / 竖向 改变围巾的摆放方向；🎲 换个纹理 随机换一种纹理。
  • 点 ⬇ 下载图片 保存效果图，可以发给朋友看 ✨
  • 想做下一个作品？点 ✨ 新建项目。

⚙️设置 · 换个好看的背景

点右上角的 ⚙️ 设置：

  • 背景：奶油、蜜桃、格纹、波点……也可以选自己喜欢的颜色，或者上传自己的图片当背景。
  • 外观：浅色 / 深色模式、主题色、文字大小。
  • 默认参数：常用的拼豆品牌、毛线粗细等。

设置会自动保存，下次打开还在。

❓ 常见问题

遇到的情况怎么办
上传后提示「无法读取」照片可能是 HEIC 格式。截个屏，或者转成 JPG 再上传。
「自动识别」数得不对先把裁剪框调得更贴合作品边缘，再试一次；或者直接手动填豆子数。
图纸颜色和实物不一样换一个拼豆色卡试试；或者在第 3 步用画笔、替换颜色手动修正。
图纸上有很多杂色小点把「最多颜色数」调小。
想回到前面某一步直接点页面顶部的步骤名称，或者点「上一步」。
关掉网页后东西还在吗？图纸和设置会保留；但原照片不会保存，需要的话重新上传。
网页卡住了围巾效果图需要几秒钟绘制，稍等一下；实在不行就刷新页面。
